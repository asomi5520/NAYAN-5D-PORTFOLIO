# Nayan Hira — 5D AI Portfolio

A futuristic interactive portfolio built with:

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL
- GSAP
- ScrollTrigger

## Features

- Cinematic loader
- 3D AI core
- WebGL particles
- Interactive orbital rings
- Mouse parallax
- Custom cursor
- Magnetic interactions
- Horizontal project scrolling
- Scroll animations
- Responsive design
- Mobile navigation
- Futuristic typography
- AI developer portfolio layout

## Run Locally

Because ES modules are used, run the project through a local server.

For VS Code:

1. Install Live Server.
2. Open the project.
3. Right click `index.html`.
4. Select "Open with Live Server".

## Customize

- Name

- Projects

- GitHub links
